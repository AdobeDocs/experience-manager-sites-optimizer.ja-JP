# プリフライトへのアクセス

プリフライトは、ユニバーサルエディター、ドキュメントベースのオーサリング、AEM Sites ページエディターなど、AEM Sitesのオーサリング環境で使用できます。 プリフライトは、オーサリングするページにパネルとして開きます。 パネルから、そのページで[監査](./audits.md)を実行し、プリフライト [は、公開前にページを強化するために見つかった商談](./audit-results.md)を表示します。

* **ユニバーサルエディター** - プリフライト拡張機能が&#x200B;**サイドパネル**&#x200B;に表示されます。 選択してプリフライトパネルを開きます。
* **ドキュメントベースのオーサリング** - プレビューしたページコンテンツで、Sidekickまたはブックマークレットからプリフライトパネルを開きます。
* **AEM Sites ページエディター** - ブラウザーのプリフライトブックマークレットを使用して、プリフライトパネルを開きます。

パネルが開いたら、「**ページを分析**」を選択して、現在のページの監査を開始します。

設定手順について詳しくは、[プリフライト設定](./setup.md)を参照してください。
