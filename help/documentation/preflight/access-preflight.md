# プリフライトへのアクセス

プリフライトは、ユニバーサルエディター、ドキュメントベースのオーサリング、AEM Sites ページエディターなど、AEM Sites のオーサリング環境で使用できます。 プリフライトを開くと、オーサリング中のページのパネルが表示され、そのページで[監査を実行](./audits.md)し、公開前にページを強化するために見つかった[機会を表示](./audit-results.md)します。

* **ユニバーサルエディター** - プリフライト拡張機能が&#x200B;**サイドパネル**&#x200B;に表示されます。 これを選択すると、現在のページの監査が開始されます。
* **ドキュメントベースのオーサリング** - Sidekick またはブックマークレットを経由して、プレビュー済みのページコンテンツでプリフライトツールを実行し、機会のリストを表示します。
* **AEM Sites ページエディター** - ブラウザーのプリフライトブックマークレットを使用して、監査を開始します。

設定手順について詳しくは、[プリフライト設定](./setup.md)を参照してください。
