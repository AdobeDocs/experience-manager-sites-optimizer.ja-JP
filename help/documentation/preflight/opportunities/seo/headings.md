# 見出しの監査

**見出し**&#x200B;監査では、ページの見出し構造がレビューされます。 明確で順序付けされた見出しの階層は、読者と検索エンジンの両方が、コンテンツがどのように整理されているかを理解するのに役立ちます。 この監査では、レベルをスキップする見出しや順番に表示されない見出しなどの問題が検出されます。

監査で商談が見つかると、各見出しが特定され、推奨される変更が説明されます。 オポチュニティのレビューと解決方法については、[ プリフライトでの監査結果](../../audit-results.md)を参照してください。
