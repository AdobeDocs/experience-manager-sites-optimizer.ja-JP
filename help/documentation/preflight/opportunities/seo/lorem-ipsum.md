# Lorem ipsum audit

**Lorem ipsum**&#x200B;監査は、ページコンテンツに残っているプレースホルダーテキストを検出します。 プレースホルダーテキストを含むページを公開すると、読者には未完成のように見え、検索エンジンでインデックスを作成できます。 監査では、プレースホルダーテキストにフラグが付けられるので、公開前に実際のコンテンツで置き換えることができます。

監査で商談が見つかると、それぞれプレースホルダーテキストが表示される場所を特定します。 オポチュニティのレビューと解決方法については、[ プリフライトでの監査結果](../../audit-results.md)を参照してください。
