# ボディサイズ監査

**ボディサイズ**&#x200B;監査では、ページ上のボディコンテンツの量がレビューされます。 コンテンツが非常に少ないページは、読者にとって有用でないことがあり、検索結果でランクが低くなる可能性があります。 監査では、コンテンツが不十分と思われるページにフラグが付けられます。

監査で機会が見つかると、それぞれ問題と推奨される変更を説明します。 オポチュニティのレビューと解決方法については、[&#x200B; プリフライトでの監査結果](../../audit-results.md)を参照してください。
