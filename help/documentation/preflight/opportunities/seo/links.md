# リンク監査

**リンク**&#x200B;監査では、ページ上のリンクがレビューされます。 壊れたリンクや安全でないリンクは、ユーザーエクスペリエンスを損ない、検索エンジンがサイトをクロールする効果を低下させる可能性があります。 監査では、注意が必要なリンクにフラグが付けられるので、公開前に修正することができます。

監査で商談が見つかると、各商談は影響を受けるリンクを特定し、推奨される変更を説明します。 オポチュニティのレビューと解決方法については、[ プリフライトでの監査結果](../../audit-results.md)を参照してください。
