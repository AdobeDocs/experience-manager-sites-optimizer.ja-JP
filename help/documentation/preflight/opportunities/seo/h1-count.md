# H1 カウント監査

**H1 count**&#x200B;監査では、ページのH1見出しの数が確認されます。 一般的に、ページには、コンテンツを要約した、わかりやすい単一のH1が必要です。 H1見出しが見つからないか、複数ある場合、ページの構造と検索エンジンの最適化が低下する可能性があります。

監査で機会が見つかると、それぞれ問題と推奨される変更を説明します。 オポチュニティのレビューと解決方法については、[ プリフライトでの監査結果](../../audit-results.md)を参照してください。
