# 正規監査

**正規**&#x200B;監査では、ページ上の正規リンクがレビューされます。 適切な規範的リンクを設定すれば、どのURLがページの信頼できるバージョンであるかが検索エンジンに通知され、コンテンツの重複を防ぐことができます。 監査では、見つからないか正しくない正規リンクにフラグが付けられます。

監査で機会が見つかると、それぞれ問題と推奨される変更を説明します。 オポチュニティのレビューと解決方法については、[&#x200B; プリフライトでの監査結果](../../audit-results.md)を参照してください。
