# 読みやすさの監査

**読みやすさ**&#x200B;監査では、ページコンテンツを簡単に読み取れるようにレビューします。 明確で構造化されたコンテンツは、オーディエンスの関心を維持し、より多くのオーディエンスがメッセージを理解するのに役立ちます。 監査では、コンテンツを評価し、改善のための実用的な推奨事項を提示します。

Readability auditは、次のような複数の言語のコンテンツをサポートしています。

* 英語
* フランス語
* スペイン語
* イタリア語
* ドイツ語
* オランダ語

監査で機会が見つかると、それぞれ問題と推奨される変更を説明します。 オポチュニティのレビューと解決方法については、[&#x200B; プリフライトでの監査結果](../../audit-results.md)を参照してください。
