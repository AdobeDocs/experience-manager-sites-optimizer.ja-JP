# SEO監査

![ プリフライト準備状況ダッシュボードでのSEO監査](./assets/seo/hero.png){align="center"}

プリフライトの&#x200B;**SEO** カテゴリは、ページが検索エンジン向けに最適化されているかどうかを評価する監査をグループ化します。 プリフライト監査を実行すると、これらの監査により、ページのメタデータ、見出し構造、リンク、コンテンツが評価され、公開前にレビューして解決できる機会が表示されます。

準備状況ダッシュボードで、**SEO** カテゴリを展開して、各監査が合格したかどうか、見つかった商談数を確認します。 監査を選択して詳細ページを開き、商談を処理します。 結果を解釈して機会を解決する方法については、[ プリフライトでの結果の監査](../audit-results.md)を参照してください。

SEO カテゴリには、次の監査が含まれます。

* [ メタタグ ](./seo/metatags.md) - ページタイトルとメタディスクリプション タグを確認します。
* [見出し](./seo/headings.md) - ページの見出し構造と順序を確認します。
* [H1 count](./seo/h1-count.md) - ページのH1見出しの数を確認します。
* [ リンク ](./seo/links.md) - ページ上のリンクを確認します。
* [読みやすさ](./seo/readability.md) - ページコンテンツを簡単に読み取れることを確認します。
* [正規](./seo/canonical.md) - ページの正規リンクを確認します。
* [ ボディサイズ ](./seo/body-size.md) - ページ上のボディコンテンツの量を確認します。
* [Lorem ipsum](./seo/lorem-ipsum.md) - コンテンツに残っているプレースホルダーテキストを検出します。
