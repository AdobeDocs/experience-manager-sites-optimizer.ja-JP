# ASO Doc Agent – 学習内容の確認

このエージェント独自のPRに関する人間のPR レビューのフィードバックから抽出された耐久性のある教訓。 読み取り

## ここに属するもの

**一般化可能**のフィードバックのみ – 将来のチケットに繰り返されるパターン
トーン、構造、欠けているセクション、誤ったファイル配置、またはコンテンツの精度。 例：

- 「無視/スキップをサポートする商談については、常に無視タブについて言及してください。」
- 「チケットまたは既存の兄弟ページが確認しない限り、Ultimate層のゲートを主張しないでください。代わりに、コメントを残してオープンアイテムとしてフラグを立てます。」
- 「新しい商談ハウツーのページには、ページ自体だけでなく、商談タイプのランディングページにTOC.md エントリとカードグリッドエントリが必要です。」

## ここに属していないものは

単発の機械的なフィードバックで、1つのPRにのみ適用されます：タイプミス、リンク切れ、リンク切れ
コンマがありません。特定のPRのファイルパスが間違っています。 PRで直接修正する
将来のドラフトに一般化しないので、耐久性のあるエントリはノイズになります。

## エントリ形式

```markdown
## YYYY-MM-DD — SITES-XXXXX (PR #NN)

**Lesson:** [one or two sentences — the generalizable rule]

**Why:** [what the reviewer actually said, or the specific mistake it corrects]

**Applies to:** [which ticket types / pages this affects — "all opportunity how-to pages", "settings/setup pages", "everything", etc.]
```

最新のエントリを一番上に表示します。 後のレッスンが前のレッスンに取って代わるか狭くなる場合は、編集します
前のエントリでは、ファイル内に2つの競合するルールを残す代わりに、に注意してください。
