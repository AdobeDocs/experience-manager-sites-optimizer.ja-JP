# Experience League ビデオのアップロード

## 概要

Experience League ビデオは、このリポジトリではホストされません。ローカル `.mp4`が別の送信フォームを通じてアップロードされ、その後`>[!VIDEO](...)`に埋め込んだ`video.tv.adobe.com` URLが返されます（[[experience-league-markdown]]を参照）。 このスキルは、ファイルの添付と送信を含まない（含まない）まで、ブラウザーの自動化を介してフォームに入力します。

フォーム：https://81368-exlmpcvideoupload.adobeio-static.net/#/

## ビデオファイルのレコメンデーション

ユーザーがクリップを録画または選択する前に、**16:9 アスペクト比**&#x200B;を&#x200B;**最大解像度1920 x 1080 ピクセル**&#x200B;でレコメンドします。これは、スタイル設定だけでなく、フォーム独自の要件です。 これを積極的に言及してください（例えば、ユーザーがこれを行うための画面録画をキャプチャしようとしていると言った場合）。

## ハードルール：ファイルを添付しない、または送信しない

送信すると、実際のKT Jira チケットが作成され、実稼動動画プラットフォームにアップロードされます。これは、外向きで逆向きのアクションです。 **常に**&#x200B;他のすべてのフィールドに入力したら停止し、次回に指示を繰り返さない場合でも、ビデオ ファイルと最終的な送信のクリックのためにユーザーに戻します。 これは、このスキルのデフォルトであり、リクエストごとに再確認が必要なものではありません。ユーザーが同じリクエストで送信するように明示的に指示した場合にのみ、この停止をスキップします。

## 前提条件

`chrome-devtools` MCP サーバーが必要です。このリポジトリには&#x200B;**not**&#x200B;がコミットされています（ブラウザーの自動化MCPはすべてのコントリビューターに強制しないでください）。 読み込まれていない場合：

1. リポジトルートに`.mcp.json`を作成します。

   ```json
   {
     "mcpServers": {
       "chrome-devtools": {
         "command": "npx",
         "args": ["-y", "chrome-devtools-mcp@latest", "--accept-insecure-certs", "--no-usage-statistics"]
       }
     }
   }
   ```

2. `.mcp.json`を`.gitignore`に追加します（個人用ツール、共有なし）。
3. `.claude/settings.local.json`で、`"enableAllProjectMcpServers": true`と`"enabledMcpjsonServers": ["chrome-devtools"]`を追加します。
4. Claude Codeを再起動するようユーザーに指示します（または`/mcp`を実行） — MCP サーバーは起動時にのみ読み込まれます。これはセッション中に実行することはできません。

## このリポジトリのデフォルト

ユーザーが別途指定しない限り、次を使用します。

| フィールド | デフォルト | 理由 |
|---|---|---|
| クラウド | `Experience Cloud` | — |
| 製品 | `AEM` | このリポジトリのユーザー指定のデフォルト （フォームにも`AEM as a Cloud Service`が一覧表示されます。要求されない限り置き換えないでください） |
| 下位積 | `AEM Sites` | 最も近い一致。フォームに「Sites Optimizer」エントリがありません |
| roles | `User` | プリフライト/Sites Optimizer コンテンツは、技術的なオーディエンス向けにビデオが明確に作成されていない限り、管理者/開発者ではなく、作成者/マーケターを対象としています |
| スキルレベル | `Beginner` | 表示されるワークフローに実際の前提条件がない限り |
| ビデオ音声の性別 | `No voices` | 無音スクリーン録画の場合のみ – クリップにナレーションがあるかどうかを確認します |
| ビデオタイプ | コンテンツから推測したり、質問したりする | ライブオプションは`Event` / `Feature` / `Technical` / `Value`です。通常、UI ウォークスルーは`Feature`です |
| メール | 事前入力された属性を使用して | このフォームは、ログインユーザーのAdobe メールに自動入力されます。上書きしないでください |

## 手順

1. `mcp__chrome-devtools__new_page`をフォーム URLに送信します。
2. `mcp__chrome-devtools__take_snapshot`とフォームデータの読み込みが完了するまで（`"Title"`の`mcp__chrome-devtools__wait_for`）待ちます。「フォームデータの読み込み中」から開始します。 スピナー：
3. 「**タイトル**&#x200B;および&#x200B;**説明** – 説明はコンテンツ編集可能なリッチテキストボックスであり、プレーン `<textarea>`ではありません。 `fill`/`fill_form`はサイレントにno-opsを実行します（値は受け取らず、「必須」エラーは残ります）。 代わりに、`click`にフォーカスし、次に`mcp__chrome-devtools__type_text`にテキストを配置します。
4. ドロップダウン（**ビデオタイプ**、**ビデオ音声**、**クラウド**、**製品**、**サブ製品**、**イベント名**）は、ネイティブの`<select>`ではなく、カスタムリストボックスボタンです。 各：`click` ボタンを開くには、スナップショットから実際のオプションを読み取ります（APIが読み込まれています。デフォルトのテーブルの正確なオプションのスペルがまだ最新であると仮定しないでください）。次に、一致する`option`を`click`します。
5. **製品**&#x200B;および&#x200B;**サブプロダクト**&#x200B;は、親フィールドが設定されるまで無効になります（製品にはCloudが必要、サブプロダクトには製品が必要）。その順序で入力してください。
6. **役割**&#x200B;と&#x200B;**スキルレベル**&#x200B;はチェックボックスグループです – `fill_form`と`"value": "true"`はチェックボックス `uid`の上で正常に機能します（説明フィールドとは異なります）。
7. 停止。 スクリーンショットを撮り、何が設定されたのか、その理由（特に製品/サブプロダクトなど、置き換えられたデフォルト）を要約し、ビデオを添付して自分で送信するようにユーザーに指示します。
8. ユーザーが送信済みであることを確認したら、結果として得られるAdobe MPC ビデオのURL （アップロード後のフォームに表示されます。例：`https://video.tv.adobe.com/v/3496629?learn=on`）を尋ねます。 このビデオが行く予定の`>[!VIDEO](...)` ショートコードを入力するために使用します。URL/IDを自分で作成したり推測したりしないでください。

## 返されたビデオ URLの検証

ユーザーが埋め込むビデオ URLを渡すたびに（上記の手順8またはその他の時間）:

- **`video.tv.adobe.com`に含まれない項目を拒否します。** ビデオは[[experience-league-markdown]]ごとにホストする必要があります。YouTube、ファイルホスト、またはその他のドメインへのリンクは、有効な`>[!VIDEO]` ターゲットではありません。 最初にこのリポジトリのアップロードフローを経由する必要があることをユーザーに伝えます。埋め込まないでください。
- **有効な`video.tv.adobe.com` URLが`&enablevpops`にない場合は、埋め込む前に**&#x200B;を追加します（このリポジトリ内の他のすべての`>[!VIDEO]`で既に使用されている規則と一致します – `help/home.md`、`help/documentation/trial.md`などを参照）。 既に`?`がある場合は`&enablevpops`、それ以外の場合は`?enablevpops`を追加します。

## よくある間違い

- 「説明」フィールドで`fill`/`fill_form`を試し、エラーバナーに「説明が必要です」と表示されたときに続行します。  – 最後だけでなく、各ステップの後にエラーリストを確認します。
- ドロップダウンを開く代わりにメモリからドロップダウンオプションのテキストを推測する – ドロップダウンを開く代わりに、実際の値（例：音声性別の`No voices`、ビデオタイプの`Feature`/`Technical`/`Value`、製品の下のAEM/AEM-as-a-Cloud-Serviceの分割）は推測できず、このドキュメントとは独立して変化します。
- 「**ビデオをアップロード** / ファイルの添付」をクリックして、「手順をユーザーに保存する」をクリックします。 悪い例：上記の「ハードルール」を参照してください。
